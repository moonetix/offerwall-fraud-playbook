# Changelog

All notable changes to the playbook and its code. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-11-11

### Added

- Twelve chapters: threat model; account farms and referral rings; VPN, proxy, datacenter and residential proxy traffic; emulators and device farms; postback forgery and replay; reversals, holds and clawbacks; cash-out fraud; KYC-lite signals; what to log; review queues; a 30-point launch checklist; incident response.
- Reference SQL schema and seven detection queries.
- Node.js snippets: postback verification, hold ledger with referral clawbacks, IPv4 and IPv6 range matching, account linking, risk tiers.
- PHP postback handler with the same ledger.
- Tests against postbacks signed by the Moonetix postback code.
